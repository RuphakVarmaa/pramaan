## Diagrams and graphics

All diagrams in this repo (the architecture triangle in README.md and ARCHITECTURE.md, the flow diagrams, the evidence-pack dossier design in `src/templates/evidence.ts`) are in-repo originals authored for Pramaan — no stock imagery, no external assets. `metrics/chart.svg` (S5) is generated by the batch runner from measured numbers, not imported.

## Icons

All icons in the console (`web/`) are original inline SVG (including the प्रमाण seal motif favicon at `web/public/favicon.svg`). No icon-font CDNs, no third-party icon sets.

## Fonts used by the evidence pack

The dossier itself renders serif-forward with a **system serif stack** (Georgia / 'Iowan Old Style' / 'Times New Roman') so the generated HTML stays fully self-contained when saved or emailed — no webfonts fetched, no external requests, by design. The self-hosted Newsreader set above belongs to the console (a desk); the dossier (a document) intentionally uses the reading system's own serifs. The two type systems are deliberately separate.
